Street Knowledge

GPS navigation with your own car on the map, live friends, shared pins and chat.

⬇ Download for Android

Android 6.0 or newer · version 1.0.2

🤖 Install on Android

  1. Tap Download for Android and open the downloaded StreetKnowledge.apk.
  2. If asked, allow Install unknown apps for your browser or file manager (Settings → Apps → that app → Install unknown apps), then go back.
  3. Tap Install.
  4. If Google Play Protect warns about an unknown app, tap More details → Install anyway.
  5. Open Street Knowledge and allow location access.

🍎 iPhone / iPad

The iPhone app isn't in the App Store yet. Use the web app instead; it works like an app:

  1. Open Street Knowledge in Safari.
  2. Tap the Share button (square with an arrow).
  3. Choose Add to Home Screen, then Add.
